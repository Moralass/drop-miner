# Drop Miner

Десктоп-планировщик Twitch Drops для нескольких аккаунтов.

- `desktop/` — Tauri 2 + React (приложение)
- `backend/` — Fastify + Prisma + PostgreSQL (auth, подписки Stripe, лицензии, админ-API, ИИ)
- `admin/` — веб-админка (статическая страница)
- `landing/` — SEO-лендинг и страницы возврата из Stripe
- `docs/PLAN.md` — архитектура, деплой, ограничения, дорожная карта

Быстрый старт — см. раздел 4 в `docs/PLAN.md`.

Версия 0.4: мониторинг эфиров, уведомления, ключи с блокировкой. Что проверено и что нет — раздел 6 в `docs/PLAN.md`.
